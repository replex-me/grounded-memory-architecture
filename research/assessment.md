# 연구 판단: 경험에서 갱신되는 기억 관리 아키텍처

기준일: 2026-10-14. 이 문서는 설계 판단과 근거 비교다. 실험으로 입증하지 않은 개선 효과를 사실로 쓰지 않는다.

## 대상의 수준

설계 대상은 경험→기억 형성→관계 조직→근거에 따른 갱신→업무에서의 회상이라는 순환을 정의하는 **기억 관리 아키텍처**다. 형식 표준은 이를 교환하는 명세이며, 프로그램은 구현이다. 둘 다 아키텍처의 부속 결과다. 사고·행동·지각 전체를 정의하는 인지 아키텍처보다 좁고, 그래프 형식이나 메타데이터 표준보다 넓다.

| 비교 대상 | 실제 수준 | 이 설계와의 관계 |
| --- | --- | --- |
| Hindsight | 사실·경험·관찰·믿음과 저장·회상·성찰을 조직하는 기억 아키텍처 | 경험과 믿음을 구분하는 가까운 비교 대상 |
| Eywa | 불변 원자료를 먼저 보존하고 근거 있는 기억을 형성·갱신·삭제하는 기억 아키텍처 | 원자료와 현재 기억 분리의 매우 가까운 비교 대상 |
| A-MEM | 새 입력으로 기억의 연결과 표현을 갱신하는 기억 관리 방식 | 의미 단위와 동적 연결의 가까운 비교 대상 |
| HippoRAG 2 | 비모수적 지속 학습과 연결을 활용한 회상 프레임워크 | 통합·연상·회상 평가 대상 |
| Graphiti | 시간과 출처가 있는 그래프 관리 프레임워크 | 시간·이력·국소 갱신의 구현 참고 |
| ACT-R·Soar | 지식과 기억뿐 아니라 사고·행동을 다루는 인지 아키텍처 | 큰 범위의 이론 참고이며 동급 범위로 주장하지 않음 |
| CoALA | 언어 에이전트의 기억·행동·의사결정 구성 요소를 정리하는 아키텍처 프레임워크 | 우리 기억 관리 영역이 전체 에이전트에서 어디에 놓이는지 설명하는 상위 분류 |
| RDF·SKOS·PROV·Web Annotation | 표현·개념 조직·출처·구간 연결의 표준 | 교환 명세에 재사용하는 기반 |
| Zettelkasten | 연결된 노트로 이해를 발전시키는 지식 작업 방법 | 탐색과 의미 단위의 실무 참고 |

같은 비교 범주는 같은 성능·과학적 완성도·표준 지위를 뜻하지 않는다. Hindsight의 네 네트워크를 그대로 복사할 이유도 없다. 여기서는 사용자가 정한 입력 기록/현재 기억 경계와 원인 있는 갱신을 중심으로 최소화한다.

2026년 Eywa의 공개 논문 요약에서도 원자료를 먼저 불변 보존하고 기억을 출처에 묶는 구조가 확인된다. 따라서 원자료→기억→갱신이라는 구조 자체를 새 발명이나 독점적인 차별점으로 주장하지 않는다. 이 초안의 제안은 위키 관리에 맞춘 연결 경계, 의미·상태 전이 계약과 구현 독립적인 검증 사례다. 과학적 신규성은 별도 선행연구 검토가 필요하다. [Eywa](https://arxiv.org/abs/2605.30771), [CoALA](https://arxiv.org/abs/2309.02427).

## 5번의 왜가 실제로 바꾸는 설계

1. **왜 기록을 남기는가?** 다음 사람이 같은 상황을 다시 이해하고 더 나은 판단을 하기 위해서다. 따라서 보관량이나 등록 건수를 성공 지표로 삼지 않는다.
2. **왜 원본만으로는 충분하지 않은가?** 매번 모든 경험을 다시 읽어 현재 판단을 복원해야 하기 때문이다. 따라서 현재 기억을 별도로 형성하되 원본에 돌아갈 수 있게 한다.
3. **왜 요약 하나로는 충분하지 않은가?** 요약은 무엇이 무엇을 뒷받침하는지, 반례와 조건이 어떻게 다른지 잃을 수 있다. 따라서 기억의 적용 조건과 관계를 남긴다.
4. **왜 연결된 기억만으로는 충분하지 않은가?** 전제가 바뀌어도 결론이 과거 상태로 남을 수 있다. 따라서 근거 변경과 검토 만료를 전달한다.
5. **왜 자동 점수 갱신만으로는 충분하지 않은가?** 같은 자료의 반복, 잘못된 측정, 다른 조건의 경험과 목표의 변경을 구분하지 못하기 때문이다. 따라서 원인 기록·독립성·조건·채택과 실증의 구분이 최소 계약이 된다.

여기서 남는 본질은 **이해에 필요한 의미와 근거를 보존하면서, 경험이 바꾼 부분만 설명 가능하게 수정하는 것**이다. 위 다섯 단계는 설계 목적의 논증이지 조직 장애 원인의 실증 인과 분석이나 인간 기억의 유일한 존재 이유를 증명하는 실험이 아니다.

## 기억 과학: 채택할 것과 닮지 않은 것

뇌에서 기억은 특정 문서나 단일 부위에 그대로 저장되는 것이 아니다. 기억 흔적의 분산, 기억 간 연결, 재활성화와 회로 변화가 연구된다. 2025년 동물 연구는 시간에 따른 해마 회로의 재조직과 기억의 정밀성·일반화 변화도 보여준다. 따라서 경험이 기존 표현과 관계를 변화시킨다는 원리를 참고할 수 있다. 그러나 하이퍼링크가 시냅스와 같은 것이라는 결론은 나오지 않는다.

특히 **단기기억끼리 연결하지 않는 규칙은 생물학적 사실이 아니다**. 실제 경험 기억끼리도 연결된다. 이 규칙은 원자료 관리 복잡도를 줄이고 현재 지식의 연결에 집중하는 업무용 프로파일이다. 오래 보존하는 원자료를 신경과학의 단기기억과 동일시하지 않는다. 여기의 역할 구분은 경험 기록과 현재 의미 기억의 구분에 더 가깝다.

‘생존과 효율’은 목적과 비용을 고려하는 설계의 출발 은유가 될 수 있다. 이를 모든 기억·지식·관계의 완전한 과학적 정의나 하나의 점수로 쓰지 않는다. 제도·규범·탐구·타인과 공유하는 이해에는 효력과 정확성 등 서로 다른 평가가 필요하다.

## 기억·지식·관계의 차이

- **기억:** 이후 다시 활용할 수 있도록 남긴 경험이나 의미의 표현. 남아 있다는 것만으로 정확하지는 않다.
- **지식:** 근거와 조건을 검토해 현재 사용할 수 있는 이해. 이 시스템은 ‘현재 사용할 판단’을 관리할 수 있지만 철학적으로 참인 지식을 자동 인증하지는 못한다.
- **관계:** 두 기억의 단순 근접성이 아니라 함께 읽기, 지지, 반박, 적용 전제, 정정 등 어떤 역할을 하는지를 나타내는 연결. 관계도 틀릴 수 있으므로 근거와 철회가 필요하다.

인식론의 정당화·믿음·참을 둘러싼 논의는 근거가 있다고 해서 지식이 자동 성립하지 않는다는 한계를 환기한다. 실용주의의 탐구 관점에서는 불확실한 이해를 경험으로 시험하고 수정하는 과정이 중요하다. 이 관점은 특정 점수의 최대화보다 정정 가능성, 근거 추적, 반례 보존이라는 설계 선택으로 이어진다.

Jon Doyle의 진리 유지 시스템은 믿음의 이유와 의존을 관리하는 선행 연구다. 자연어를 자동 논리 증명으로 바꾸지는 않되, 전제 변경이 결론의 재검토로 이어지도록 하는 원리를 채택한다. 사실 관찰과 미션·목표의 채택 효력을 같은 방식으로 갱신하면 안 된다.

## 최신 접근과 반대 근거

| 접근 | 남기는 원리 | 그대로 도입하지 않는 이유 |
| --- | --- | --- |
| Hindsight | 근거와 해석·믿음 구분, 변화의 추적 | 대화 기억 벤치마크가 조직 위키의 채택 권한과 의미 정확성을 입증하지 않음 |
| A-MEM | 의미 단위의 연결, 새 입력에 따른 기존 기억 갱신 | 자동 링크·재서술이 관계의 타당성이나 의미 보존을 보장하지 않음 |
| Graphiti | 경험 시점과 등록 시점, 시간에 따른 사실 변화, 출처 추적 | 프레임워크의 전체 의존성과 자동 추출을 코어 명세에 강제할 필요 없음 |
| HippoRAG 2 | 통합·연상·다단계 회상 평가 | 회상 개선이 믿음 정정·권한·반례 관리의 완전성을 뜻하지 않음 |
| Mem0 | 입력에서 유용한 기억을 뽑고 기존 기억을 갱신 | 연구의 그래프 추가 이득만으로 모든 위키에 그래프가 최선이라고 할 수 없음 |
| Nested Learning | 갱신 속도와 기억 과정이 단일 이분법보다 다양할 수 있다는 관점 | 신경망 내부 최적화 연구를 외부 위키 데이터 모델의 실증 근거로 바꾸면 안 됨 |
| ReFind, 2026 | 원문에 대한 능동 검색도 강한 비교 기준 | 해당 대화 질의 실험에서는 구조화하지 않는 접근도 경쟁력 있음; 그래프 우위 전제 금지 |
| E-mem, 2026 | 압축하지 않은 경험 맥락에서 필요한 근거를 다시 구성 | 모든 맥락을 기억 그래프로 미리 바꾸는 것이 필수라는 주장과 맞지 않음; 다중 에이전트를 코어에 강제하지 않음 |
| Eywa, 2026 | 원자료 우선 보존, 추출과 회상·응답 정책 구분 | 근거 중심 접근 자체는 이미 존재함; 위키 관리의 추가 효과는 따로 입증해야 함 |
| Human-Inspired Memory Architecture, 2026 | 단순 축적의 실패 원인별 메커니즘과 평가 분리 | 공개 연구에서 일부 규모의 회상은 원문 검색과 비슷했으므로 뇌 은유만으로 우위 주장 금지 |

우리의 그래프 채택 이유는 특정 벤치마크 점수의 우위가 아니라 **근거·조건·의존에 따른 갱신을 설명하기 위해서**다. 검색만을 위해 무조건 전체 내용을 그래프로 변환하지 않는다. 희귀한 세부 사실이나 긴 논증은 원문 검색이 더 적절할 수 있다.

최근 연구·제품 발표의 성능 숫자는 같은 데이터, 모델, 평가자, 비용 조건으로 재현하지 않았으므로 직접 순위를 만들지 않는다. 공식 저장소·논문이 확인된 자료만 결정 근거로 사용한다. 회사 문서에 대한 성능은 별도 평가가 필요하다.

이번 검토는 원 논문의 공개 요약, 공식 프로젝트·표준 문서에 기반한 설계 비교다. 모든 논문의 전체 구현·데이터·실험을 재현한 체계적 문헌고찰은 아니다. 특히 제품별 정확도 수치와 생물학적 적용 범위를 독립적으로 재현하지 않았다. 이 근거 한계를 공개한 상태에서 코어의 표현·전이 규칙을 합성 자료로 검증한다.

## 후보 구조 비교와 최종 선택

| 후보 | 좋은 점 | 목적에 남는 문제 | 판단 |
| --- | --- | --- | --- |
| 원문 문서와 하이퍼링크만 유지 | 단순하고 원문에 충실 | 독립 판단의 갱신·관계 의미·변경 영향이 문서 전체에 묶임 | 원자료와 비교 기준으로 유지 |
| 모든 문장을 독립 노드로 변환 | 세밀한 연결 가능 | 조건·예외·절차의 분절, 관리량과 추출 오류 증가 | 채택하지 않음 |
| 원문+자동 요약+벡터 검색 | 유사한 내용 회상에 유리 | 의미 관계, 반례, 최신 판단을 유사도로 대체할 수 없음 | 선택적 검색 확장 |
| 원문+기억 의미 단위+근거 있는 관계+변경 | 이력과 현재 이해를 분리하고 정정 원인을 설명 | 추출·조건 동일성·독립성 판단에는 검토 필요 | 최종 코어 |
| 완전 자동 학습·확률 전파 | 자율 갱신 가능성 | 자기 강화, 권한·의도 변경, 미보정 수치 | 실험 전에는 채택하지 않음 |

## 명칭 제안의 수준

설명을 위한 명칭으로 **‘Grounded Memory Architecture’, 약칭 ‘GMA’**를 제안한다. 기억을 경험·출처·적용 조건에 묶고, 새 근거에 따라 기억과 관계를 재검토한다는 뜻이다. 소프트웨어 브랜드를 먼저 정하지 않고 아키텍처의 작동 원리를 드러내는 명칭이다. 명칭은 채택되지 않았으며 저장소 경로 memory-architecture도 고유명 확정이 아니다.

Hindsight·Eywa처럼 고유한 단어를 쓰는 방식과 A-MEM·ACT-R처럼 기능을 나타내는 명칭을 쓰는 방식이 모두 존재한다. 이 제안은 후자의 방식이다. ‘Linked Memory Model’보다 연결 이후의 근거 확인과 수정 가능성을 드러낸다. 세계 최초의 모델이나 그 명칭의 독점 사용 가능성을 주장하지 않는다.

## 공개 표준에 가까워지는 조건

공개 레포 하나를 만드는 것으로 표준이 되는 것은 아니다. 구현과 독립된 의미·상태 전이, 버전 정책, 스키마, 긍정·부정 적합성 사례, 외부 구현 간 왕복 교환과 검토 절차가 필요하다. PROV는 출처, Web Annotation은 원문 구간, Wikibase는 조건·출처가 있는 주장이라는 원리를 제공하지만 이 전체 갱신 아키텍처를 대신하지 않는다.

첫 배포는 **공개 아키텍처와 규격 초안**이다. 특정 DB를 강제하지 않는다. 작은 단일 운영 환경은 SQLite의 거래와 색인만으로 구현할 수 있으며, 독립적 다중 작성·다중 호스트 요구가 확인될 때 다른 저장 계층을 평가한다. 내부 문서와 프로그램 설정은 공개 예제에 포함하지 않는다.

남은 실증 질문은 추출 정확성, 의미 단위의 적절성, 아직 연결되지 않은 새 반례의 발견률, 실제 업무 판단의 개선, 이관 비용과 전체 입력·조회 비용이다. 형식 검사가 이 질문에 답했다고 주장하지 않는다.
